How these numbers are counted
Event window
From 00:00 on the first day to 24:00 on the last day, in the event's time zone. All activity in the window counts, remote contributions included; bot accounts (Dependabot, pre-commit) are left out.
New work, merged
PR opened during the event and merged.
Older PR reworked, merged
PR opened before the event that got new commits during it and was merged.
Backlog PR merged as-is
PR opened before the event, merged after review with no new commits.
Older PR closed (cleanup)
PR opened before the event and closed without merging.
Commits
Non-merge commits authored during the event, on the default branch or on any PR branch active during the event, each counted once.
Issue closed by a PR
The closing event names a commit, or a merged PR referencing the issue landed within ten minutes of it closing.
Typical week
Average over the weeks before the event (set per event).
Contributors
Anyone who opened a PR or issue, authored a commit or submitted a review in the window.
Not counted
Discussions, breakouts, wiki edits and PR comments that are not reviews.
